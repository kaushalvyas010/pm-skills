# Plan: Upgrading PM Skills with Thought Leader Frameworks

**Principle:** Don't mention thought leaders by name in the prompts. Embed their frameworks as structural improvements — better sections, sharper quality bars, more precise output requirements. The skill should be better because of their thinking, not because it cites them.

---

## Upgrade Approach (per skill)

For each skill, the upgrade does one or more of:
- **Add a section** that a thought leader's framework reveals is missing
- **Sharpen a quality bar** using their specific test or criterion
- **Replace vague instruction** with a precise framework

---

## Priority Tiers

### Tier 1 — Structural Gaps (framework adds a missing section)

| Skill | Framework to Embed | What Changes |
|-------|-------------------|-------------|
| **analyse-data** | Kaushik's "So What?" test | Add quality bar: every finding must pass "So what does this mean for the decision?" before it's included |
| **business-model** | Helmer's 7 Powers | Add required section: "Power Test — which of the 7 powers does this model rely on? What happens if that power erodes?" |
| **critique-product-strategy** | Rumelt's Kernel of Strategy | Replace "Core Assumption" opener with Rumelt's diagnostic: does the strategy have a diagnosis, guiding policy, and coherent actions? Missing leg = the critique. |
| **design-experiment** | Evan Miller's anti-patterns | Add "Validity Threats" section: peeking, underpowered tests, multiple comparisons, novelty effects. Require author to address each. |
| **map-assumptions** | Bland & Osterwalder's Test Card | Each prioritised assumption must be converted into a Test Card (hypothesis → test method → metric → success threshold). |
| **pricing-analysis** | Ramanujam's 4 pricing mistakes | Add "Failure Modes": feature shock, minivation, hidden gem, undead. Require explicit ruling-out of each. |
| **summarise-interviews** | Moesta's Four Forces | Add synthesis lens: push (away from old), pull (toward new), anxiety (friction), habit (attachment). |
| **value-proposition** | Dunford's 5-component canvas | Restructure positioning statement: competitive alternatives → unique attributes → value → target customer → market category. |

---

### Tier 2 — Quality Bar Sharpening

| Skill | Framework to Embed | What Changes |
|-------|-------------------|-------------|
| **create-stories** | Gottesdiener's SPIDR + Adzic's GWT | Replace "When X, then Y" → "Given / When / Then". Add SPIDR story-splitting guide. |
| **create-prototype** | Savoia's pretotype gate | Add pre-prototype gate: "Is a pretotype sufficient? Only proceed to prototype if demand signal has passed." |
| **define-metrics** | Cutler's upstream/downstream + Gilad's GIST | Add upstream/downstream test per metric. Add GIST ladder check: Goals → Ideas → Steps. |
| **internal-update** | Minto's SCR + Wes Kao's AOC | Add SCR structure for exec updates. Add AOC quality bar: Actionable, Opinionated, or Clear — delete anything that is none. |
| **interview-script** | Moesta's Switch Interview | Add JTBD probe layer: "Walk me through the moment you decided to change." Surfaces push/pull forces. |
| **write-blog-post** | Graham's surprise test + Perell's sharpness | Add quality bar: "Does this say something the reader didn't expect? What's left if you remove everything a competitor could also write?" |
| **write-prd** | Doshi's outcome/output check + Perri's Product Kata | Add check: experience or feature list? Add current vs. target condition framing. |
| **write-strategy-memo** | Rumelt's Kernel + Chin's judgment test | Add quality bar: diagnosis / guiding policy / coherent actions. A memo missing any leg fails. |

---

### Tier 3 — Framing Sharpening (existing sections, sharper framing)

| Skill | Framework to Embed | What Changes |
|-------|-------------------|-------------|
| **competitive-research** | Martin's "Where to Play / How to Win" | Strategic Implications must end with explicit "Where we play:" and "How we win:" statements. |
| **create-epics** | Patton's Narrative Backbone | Add check: "Can you narrate what users will do end-to-end once all epics are complete?" |
| **enablement** | Moesta's JTBD demand framing | Reframe "Who Cares and Why": functional job / emotional job / social job per segment. |
| **plan-launch** | Moore's Whole Product + Poyar's PLG distinction | Add Whole Product check. Add launch type declaration: sales-led / marketing-led / product-led. |
| **prfaq** | Biddle's DHM test | Add to Internal FAQs: "Does this Delight in a Margin-enhancing, Hard-to-copy way?" |
| **write-campaign-brief** | Dunford's positioning prerequisite | Add gate: positioning must be settled before brief can be completed. |
| **write-changelog** | Linear's format principles + Pickard's voice | Add rules: one change per entry, present tense, voice consistency check. |
| **meeting-notes** | Kaner's Groan Zone | Add instruction: capture productive disagreement and divergent views in Key Context. |
| **business-model** | Thompson's Aggregation Theory | Add to Failure Modes: platform/aggregator disintermediation risk. |
| **technical-deep-dive** | Orosz's practical scope | Add scope guidance: data model, API contracts, infrastructure constraints — not implementation details. |

---

## Execution Order

1. Tier 1 — structural gaps (biggest output quality lift)
2. Tier 2 — quality bar sharpening (faster edits, existing structure)
3. Tier 3 — framing changes (lowest risk, lowest lift)

One skill at a time. Test each against a sample input before moving to the next.

## What Doesn't Change

- Voice instructions (already strong across all 25 skills)
- Output length targets
- "If not provided, ask for" inputs
