# PM Go-to-Market

6 skills for GTM: launch planning, campaign briefs, PR/FAQs, changelogs, blog posts,
and sales enablement.

## Skills

| Command | Output |
|---|---|
| `/plan-launch` | Launch plan with tier, audience, core message, timeline |
| `/write-campaign-brief` | Campaign brief with single message and creative direction |
| `/prfaq` | PR/FAQ: press release + external and internal FAQs |
| `/write-changelog` | User-facing changelog entry |
| `/write-blog-post` | Blog post draft with hook, argument, revision note |
| `/enablement` | Sales/CS enablement doc: what to know, say, and do |
