# PM Product Discovery

7 skills for discovery work: customer interviews, data analysis, metrics frameworks,
experiment design, prototyping, and assumption mapping.

## Skills

| Command | Output |
|---|---|
| `/interview-script` | Discovery interview script with interviewer brief |
| `/summarise-interviews` | Interview synthesis: patterns, jobs, surprises, implications |
| `/define-metrics` | Metrics framework: north star, supporting, guardrails, leading indicators |
| `/analyse-data` | Data analysis narrative, answer-first |
| `/create-prototype` | Prototype brief with learning goal, test design, decision criteria |
| `/design-experiment` | Experiment design with falsifiable hypothesis and three outcome paths |
| `/map-assumptions` | Assumption map ranked by risk across desirability, feasibility, viability |
