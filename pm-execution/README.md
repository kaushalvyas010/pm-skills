# PM Execution

6 skills for execution: PRDs, technical deep dives, epics, user stories, internal
updates, and meeting notes.

## Skills

| Command | Output |
|---|---|
| `/write-prd` | Lean PRD: problem, solution, scope, open questions, metrics |
| `/technical-deep-dive` | Structured questions and trade-offs for engineering sessions |
| `/create-epics` | Outcome-oriented epic breakdown with sequencing |
| `/create-stories` | User stories with acceptance criteria and sizing |
| `/internal-update` | Status update calibrated to audience: exec, team, or XFN |
| `/meeting-notes` | Decisions, actions, context — not a transcript |
