# PM Product Strategy

6 skills for strategy work: strategy memos, competitive research, value propositions,
business models, and pricing analysis.

## Skills

| Command | Output |
|---|---|
| `/write-strategy-memo` | Strategy memo with a clear directional argument |
| `/critique-product-strategy` | Adversarial critique of a strategy doc |
| `/value-proposition` | Three versions: positioning statement, one-liner, paragraph |
| `/business-model` | Business model analysis with unit economics and failure modes |
| `/competitive-research` | Competitive landscape with strategic implications |
| `/pricing-analysis` | Pricing strategy with positioning and sensitivity analysis |
